# Cast Curve from Line Segment

Converts a line segment into a curve by interpolating a curve through its start and end points.

## Install

1. Download `Cast Curve from Line Segment.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Cast Curve from Line Segment**.

Last saved in nTop 5.3.2; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Line segment | line segment | Line segment to convert into a curve. |

## Output

| Output | Type |
|---|---|
| Cast Curve from Line Segment | curve |
