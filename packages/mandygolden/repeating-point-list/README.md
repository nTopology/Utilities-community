# Repeating Point List

Creates a list that repeats a point a given number of times.

## Install

1. Download `Repeating Point List.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Repeating Point List**.

Last saved in nTop 5.7.2; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Point to repeat | point | Point that is repeated. |
| Count | integer | Number of copies in the list. |

## Output

| Output | Type |
|---|---|
| Repeating Point List | list of point |
