# Treelike Supports

Creates tree-like support structures for a part.

## Install

1. Download `Treelike supports.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Tree Supports**.

Last saved in nTop 5.27.2; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

None: the block carries its example inputs inside it. Open the file to change them.

## Output

| Output | Type |
|---|---|
| Tree Supports | implicit body |
