# Move Point along a Vector

This custom block will move a point a given distance along a vector

## Install

1. Download `Move Point along a Vector.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Move Point along a Vector**.

Last saved in nTop 4.9.3; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Point | point | Point to move |
| Vector | vector | Vector to move long |
| Distance | number | Distance travelled |

## Output

| Output | Type |
|---|---|
| Move Point along a Vector | point |
