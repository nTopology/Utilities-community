# Point List as Lattice

Creates a branched lattice body that connects a list of points with beams of a given thickness.

## Install

1. Download `Point List as Lattice.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Point List as Lattice**.

Last saved in nTop 4.5.3; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Point List | list of point | Points connected by the lattice beams. |
| Thickness | scalar field | Thickness of the lattice beams. |

## Output

| Output | Type |
|---|---|
| Point List as Lattice | lattice body |
