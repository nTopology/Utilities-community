# Find Axis from Edge

This blocks enables users to find the axis of full or partial cylindrical features with their edge as the input

## Install

1. Download `Find Axis from Edge.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **CB Find Axis from Edge**.

Last saved in nTop 3.45.4; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Circular Edge | CAD edge | Input a circular CAD Edge. Partial edges are accepted. |

## Output

| Output | Type |
|---|---|
| CB Find Axis from Edge | axis |
