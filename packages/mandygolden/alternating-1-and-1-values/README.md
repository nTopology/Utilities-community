# Alternating -1 and 1 Values

Creates a list of integers that alternates between -1 and 1.

## Install

1. Download `Alternating -1 and 1 Values.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Alternating -1 and 1 Values**.

Last saved in nTop 6.3.3; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Size | integer | Number of values in the returned list. |

## Output

| Output | Type |
|---|---|
| Alternating -1 and 1 Values | list of integer |
