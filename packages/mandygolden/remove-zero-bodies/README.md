# Remove Zero Bodies

Removes empty (zero size) bodies from a list of implicit bodies.

## Install

1. Download `Remove Zero Bodies.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Remove Zero Bodies**.

Last saved in nTop 4.0.5; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Implicit Body List | list of implicit bodies | List of implicit bodies to filter. |

## Output

| Output | Type |
|---|---|
| Remove Zero Bodies | list of implicit bodies |
