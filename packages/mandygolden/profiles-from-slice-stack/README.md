# Profiles from Slice Stack

This custom block generates a list of profiles for each slice in a given slice stack

![Profiles from Slice Stack](cover.png)

_Cover: the block run on simple example inputs (spheres, boxes, curves) set up for the picture; that example notebook is not included._

## Install

1. Download `Profile from Slice Stack.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Profiles from Slice Stack**.

Last saved in nTop 5.24.3; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Slice List | list of slice | Slices that the profiles are generated from. |

## Output

| Output | Type |
|---|---|
| Profiles from Slice Stack | list of profile |
