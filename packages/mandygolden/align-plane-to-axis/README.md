# Align Plane to Axis

This cb will align a plane to a given axis.

## Install

1. Download `Align Plane to Axis.ntop`.
2. In nTop, import it from the Custom Blocks panel (or open the file to see how the block is built).
   The block appears as **Align Plane to Axis**.

Last saved in nTop 4.11.2; checked to open in nTop 6.4.3.

## Usage

Add the block to a notebook, wire the inputs below, and use its output downstream.

## Inputs

| Input | Type | Description |
|---|---|---|
| Plane | plane | Starting Plane that needs to be aligned |
| Axis | vector | Axis that the edge of the plane will align to |

## Output

| Output | Type |
|---|---|
| Align Plane to Axis | plane |
